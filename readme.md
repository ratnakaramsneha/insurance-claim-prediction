# 🏥 Insurance Claim Prediction System

This project predicts whether a hospital claim is valid and within policy limits based on the user’s inputs and policy details. It's built with Flask, scikit-learn, and a trained machine learning model.

## 💡 Features
- Web form to collect user and policy details
- Backend model to predict if the claim is valid and within limit
- Built-in input scaling with joblib scaler
- Real-time results shown on-screen

## 🛠️ Tech Stack
- **Frontend**: HTML, CSS (templates in `templates/`)
- **Backend**: Python, Flask
- **ML**: scikit-learn, joblib
- **Deployment-ready**: GitHub integration, WSGI-compatible
